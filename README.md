# 2027 摩旅西藏计划 · 乌拉盖管理区 → 拉萨

一份可以真正拿去骑的西藏摩旅计划：**33 天 / 单程 5,257 km / 日均 188 km**，全程铺装国道（G207 + G209 + G108 + G350 + G318），刻意避开 G110 煤运走廊与 G109 进藏大货走廊；车是豪爵 UFR150 踏板，露营为主。

- **动态路线图**：`2027西藏摩旅路线图_动态.html` —— 双击用浏览器打开即可（无需服务器）
- **在线版（GitHub Pages）**：<https://canglan12138.github.io/xizangMap/> —— 仓库需为 public 并在 Settings → Pages 里选 `main` / `(root)`；根目录 `index.html` 会自动跳到动态图
- **计划表格**：`2027西藏摩旅计划_乌拉盖出发.xlsx` —— 12 张表（总览 / 出行月份 / 路线与路况 / 注意事项 / 装备清单 / 预算 / 行程模板 / 打卡清单 / 高速可选 / 返程决策 / 住宿与营地 / 沿途美食）
- **轨迹文件**：`2027西藏摩旅轨迹_全程.gpx`、`2027西藏摩旅轨迹_按日.gpx` —— 可导入手机导航离线使用

## 动态路线图能做什么

| 功能 | 说明 |
|---|---|
| 逐日播放 | 播放 / 上一天 / 下一天 / 滑杆跳转，D1 → D33 |
| 信息卡 | 当日里程、到达海拔（≥4000 m 变红）、**当地必尝**、累计里程、骑行时长、加油站、高速可选 |
| 一键导航 | 卡片里「🧭 导航到 D_n 终点」调用高德 URI（`policy=3` 不走高速），手机可直接唤起 App |
| 进度记忆 | `moto2027.done` / `moto2027.cur` 存 localStorage；「✅ 记为到达」可再点一次取消，已走路段变灰；支持 `#d=22` 分享链接 |
| 搜索 | 顶部「🔍 搜索」，站名 / 垭口 / 加油点模糊匹配 |
| 清单 | 垭口 7 处 + 加油补给 59 处的清单面板，点一条跳到那天 |
| 住宿海拔柱状图 | 33 根柱子，绿 ≤3000 m / 黄 3000–4000 m / 红 >4000 m，点柱子地图飞过去 |
| 强光模式 | 白底深字，户外读数用；状态记忆在 `moto2027.day` |
| 手机适配 | 适配 iPhone 灵动岛安全区、横屏紧凑布局、底部四标签卡片坞 |

依赖两个 CDN：Leaflet 1.9.4（bootcdn）与高德瓦片（`webrd0{s}.is.autonavi.com`），**离线打开地图区域会是空白**，卡片与交互仍可用。

## 路线与关键数字

```
乌拉盖管理区 → 锡林浩特 → 太仆寺旗 → 张北 → 集宁 → 呼和浩特
  →（G209 晋陕低车流走廊）偏关 → 兴县 → 交口 → 万荣 → 风陵渡 → 西安
  →（G108 翻秦岭）佛坪 → 勉县 → 广元 → 绵阳 → 成都
  →（G350 川西环线，经卧龙/丹巴，避开折多山）新都桥
  →（G318）理塘 → 巴塘 → 芒康 → 左贡 → 八宿 → 波密 → 林芝
  →（翻米拉山垭口，隧道禁摩）墨竹工卡 → 拉萨
```

- 33 天 = 骑行 28 天 + 休整 5 天（西安 / 成都 / 林芝各 1 天，拉萨 2 天含 1 天机动）
- 最长单日 266 km、最短 71 km；不夜骑
- 预算约 1.50 万元（露营模式，含一次性装备摊销）
- 海拔阶梯：卧龙 2000 m → 丹巴 1800 m → 新都桥 3460 m → 理塘 4014 m（首个 4000 m 住宿）
- 备选 B（时间紧时）：西线压缩 4,118–4,235 km / 约 14 天，见表格

## 数据口径（重要）

- **不写店名、电话、价格**：住宿、美食只写「县城 / 街区 / 品类」，2027 年距离现在还有一年多，营业状态必然变化。
- 政策与施工信息截至 **2026-11**：边防证（本行程不需要）、散装油、G318 昌都段管制、G350 巴朗山段等，出发前必须重新核实。
- 海拔、里程来自真实路网抓取（OSRM / Valhalla / 高德），GPX 折线实测 5,309 km，比账上 5,257 km 多约 1%（抽稀拉直误差）。
- 路线结论基于「路况好 / 大车少 / 无烂路」三条筛选，**不构成安全保证**；高原骑行请自行评估身体与天气。

## 导航按钮说明（iOS / Android）

信息卡底部「🧭 导航到 Dn 终点」：

- **手机**（iPhone / Android）直接用高德 App 的 `amapuri://route/plan/` scheme 唤起**路线规划页**，不再经过网页落地页、不用再手点一次；
- 若手机没装高德，1.4 秒后自动回落到网页版 `uri.amap.com`；
- **高德 URI 协议只支持 驾车 / 公交 / 步行 / 骑行（自行车），没有“摩托车”这一项**，所以链接只能把终点带过去，进来后在高德 App 里手动点『摩托』图标（需先在 高德 → 设置 → 导航设置 里开启摩托导航）。
